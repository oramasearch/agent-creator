# AgentCreator eval runner

`run.py` keeps the generated Studio skill/work-area/code matrix and adds live App/build,
methodology and solution cases. The App case verifies the six reads, both event topic forms,
proposal-only rebuild/restart actions and confirmed delegation to ApplicationAgent. It also selects
runnable and unsupported registry entries, then verifies bindings or structured declines. An older
engine gets a solution-registry-not-deployed case. Workspace reads use lake's `workspace_query`
envelope; App and build reads use their customer-scoped lake REST capabilities.
